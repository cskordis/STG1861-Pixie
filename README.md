# STG-AVI1861

This project is a modified version of Bob Armstrong's Spare Time Gizmo STG1861 Pixie board.

It preserves the original circuit concept and overall design intent while adapting the implementation for a more compact, through-hole-friendly footprint. The board is intended to be easier to build, smaller to package, and suitable for projects where space is limited.

## Overview

The STG1861 Pixie is a classic analog-style synth / pedal / experimentation board design. This repository contains a revised variant, STG-AVI1861, that focuses on:

- Through-hole components for easier hand assembly
- Reduced board size and footprint
- Simplified layout for compact builds
- Compatibility with the original Pixie design goals

## Design Intent

The board is intended as a compact adaptation of the original STG1861 design, keeping the spirit of the original circuit while modifying the physical implementation to better suit smaller enclosures and simpler assembly workflows.
